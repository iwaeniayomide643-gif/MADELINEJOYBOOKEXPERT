# Madeline Joy Portfolio Website

## Goal
Build a complete, premium one-page portfolio that presents Madeline Joy as a book marketing and author-services specialist, using her supplied portrait and no invented portfolio work.

## Experience
- Create a rich editorial glassmorphism visual system with deep plum, ink, rose-gold, and warm ivory tones.
- Add a fixed translucent navigation bar with smooth section links and a mobile menu.
- Build a two-column opening section featuring the supplied portrait, name, specialty, biography, and two primary actions.
- Add cinematic expand/collapse biography interactions in both the opening and About sections.
- Use restrained ambient lighting, reflections, layered blur, scroll reveals, and hover motion while respecting reduced-motion preferences.

## Sections
1. **Home** — portrait, introduction, concise biography, and actions.
2. **About** — alternate portrait composition and expandable full biography.
3. **What I Do** — all 15 requested services in a polished, responsive layout.
4. **Explore My Work** — five interactive category cards, filters, and a glass detail dialog.
5. **Portfolio Detail** — reusable item structure for images, video, PDFs, screenshots, links, and testimonials; categories without supplied work show “Portfolio samples coming soon.”
6. **Process** — Discover, Plan, Create, Present.
7. **Contact** — validated name, email, book title, service, and message form with a clear non-sending confirmation state until a delivery service is connected.
8. **Footer** — concise personal brand statement and section links.

## Technical Details
- Keep portfolio data in a single typed collection so future real projects can be added, removed, and reordered easily.
- Upload the supplied portrait to project asset hosting and reuse it without modification.
- Implement accessible dialogs, keyboard handling, focus states, semantic headings, and mobile navigation.
- Lazy-load portfolio media and reserve stable media dimensions.
- Add page-specific title, description, Open Graph metadata, and Twitter card metadata.
- Verify desktop and mobile layouts, interactions, form validation, and browser console output.

## Content Integrity
- Do not fabricate clients, projects, testimonials, outcomes, or portfolio visuals.
- Use only the supplied portrait now.
- Show refined empty states for every portfolio category until Madeline supplies real materials.
